# 🌍 Geo-Conflict Map (Проект по географии)

**Geo-Conflict Map** — это интерактивная картографическая система для визуализации, изучения и анализа вооружённых конфликтов (как исторических, так и современных). Проект разработан в рамках исследования по географии и истории.

В базе данных собрана информация о более чем 220 конфликтах по всему миру, с особым фокусом на событиях последних 200 лет (включая детальную проработку конфликтов на территории Беларуси).

## ✨ Главные возможности

- 🗺️ **Интерактивная карта**: Пространственное отображение конфликтов с использованием MapLibre GL. Маркеры меняются в зависимости от масштаба события (глобальный, региональный, локальный).
- ⏱ **Временная шкала (Timeline)**: Возможность фильтровать конфликты по годам и наблюдать за ходом истории.
- 🔍 **Умные фильтры**: Сортировка конфликтов по статусу (активный, замороженный, завершённый), причинам (территориальные, политические, этнические) и количеству участников.
- ⚖️ **Режим сравнения**: Возможность выбрать до 6 конфликтов одновременно для наглядного сравнения жертв, причин и количества беженцев.
- 📖 **Детальная картотека**: Карточка каждого события содержит даты, описание, список сторон (с флагами), число жертв и ссылки на источники.

## 🛠 Технологии (Tech Stack)

- **Frontend**: React 19, Vite, MapLibre GL JS.
- **Backend**: Python 3, Django, Django REST Framework, SQLite.
- **Desktop Build**: PyInstaller (сборка в единый `.exe` файл для Windows).

## 🚀 Как запустить проект

### Вариант 1: Запуск готового приложения (Windows)
Просто скачайте и запустите файл `ConflictMap.exe`. Приложение автоматически поднимет локальный сервер и откроет светлую интерактивную карту в вашем браузере.

### Вариант 2: Запуск для разработки (Dev-режим)
Убедитесь, что у вас установлены **Python 3.10+** и **Node.js 18+**.

1. Запустите скрипт `start.bat` (для Windows) или `start.sh` (для Linux/macOS) в корне проекта.
2. Скрипт автоматически установит зависимости, запустит Django-бэкенд на порту `:8000` и Vite-фронтенд на порту `:5173`.
3. Карта откроется в браузере по адресу `http://localhost:5173`.
